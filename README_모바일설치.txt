신혼여행 플래너 · 설치 가능한 모바일 앱(PWA) v6

[핵심]
이 폴더는 iPhone/Android 홈 화면에 설치 가능한 PWA 배포 패키지입니다.
휴대폰에 실제 앱으로 설치하려면 이 폴더를 HTTPS 웹주소에 한 번 배포해야 합니다.
file:// 로 HTML을 직접 여는 방식은 운영체제 보안정책 때문에 PWA 설치가 되지 않습니다.

[GitHub Pages로 배포 - 권장]
1. GitHub에서 새 저장소를 만듭니다.
2. ZIP을 풀어 나온 파일/폴더를 저장소 최상위(root)에 업로드합니다. (.github 폴더 포함)
3. 저장소 Settings > Pages > Source에서 GitHub Actions를 선택합니다.
4. main 브랜치에 업로드/Push하면 포함된 pages.yml이 자동 배포합니다.
5. Actions 완료 후 Pages에 표시되는 https://...github.io/... 주소를 휴대폰에서 엽니다.

[iPhone/iPad 설치]
Safari 접속 > 상단의 '앱 설치' 버튼(안내) 또는 Safari 공유 버튼 > 홈 화면에 추가 > 추가

[Android 설치]
Chrome 접속 > 앱 내 '앱 설치' 버튼 > 설치
(브라우저에 따라 메뉴 > 앱 설치/홈 화면에 추가로 표시될 수 있음)

[앱 기능]
- 홈 화면 앱 아이콘, 브라우저 주소창 없는 standalone 실행
- 일정/예산 수정, 완료 체크 상태 로컬 저장
- 날짜 스와이프 및 장소별 지도 시점 이동
- 주소/전화/운영시간/홈페이지 장소 카드
- 앱 화면/인포그래픽 오프라인 캐시
- 네트워크 상태와 앱 업데이트 안내
- 실제 지도, 실시간 길찾기, 장소 최신정보는 인터넷 연결 필요

[폰트]
Noto Sans KR 온라인 웹폰트를 우선 사용하며 오프라인에서는 휴대폰 시스템 한글 폰트로 자동 대체됩니다.
